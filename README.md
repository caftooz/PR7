# Практическая работа №7. Отладка программы — Задание 1

## Консольное приложение «Фибоначчи» (DotNetDebugging)

### Описание

Консольное приложение для вычисления N-го числа последовательности Фибоначчи. В исходном коде содержалась логическая ошибка: программа возвращала значение `Fibonacci(4)` вместо запрошенного `Fibonacci(5)`.

### Обнаруженная ошибка

В цикле `for` использовался оператор строгого сравнения `<` вместо `<=`, из-за чего последняя итерация цикла не выполнялась:

```csharp
// Было (ошибка):
for (int i = 2; i < n; i++)

// Стало (исправлено):
for (int i = 2; i <= n; i++)
```

### Использованные способы отладки в Microsoft Visual Studio

**1. Точки останова (Breakpoints)**

Установлены на ключевых строках: вызов функции `Fibonacci(5)` (строка 1), внутри тела цикла `for` (строка 14) и перед оператором `return` (строка 18). Точки останова позволили приостановить выполнение программы и проанализировать её состояние в критических местах.

**2. Пошаговое выполнение (Step Over / Step Into)**

Команда **Step Into** (F11) использовалась для входа в функцию `Fibonacci()`, а **Step Over** (F10) — для построчного прохождения цикла `for` с отслеживанием изменений переменных на каждой итерации.

**3. Продолжение выполнения (Continue, F5)**

Использовалось для перехода между итерациями цикла без пошагового прохождения каждой строки, с остановкой на установленных точках останова.

**4. Окно «Видимые» (Autos)**

Использовалось для наблюдения за текущими значениями переменных `n1`, `n2` и `sum` на каждой итерации цикла, что позволило убедиться в корректности промежуточных вычислений и выявить момент преждевременного выхода из цикла.

Позволило просмотреть цепочку вызовов `Main → Fibonacci` и убедиться в корректном потоке выполнения программы.
