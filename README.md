# Практическая работа №7. Отладка программы — Задание 3

## Консольное приложение «Буквы» (GetStartedDebugging)

### Описание

Консольное приложение, которое поэлементно перебирает массив символов, формирует строку-имя и вызывает метод `SendMessage` на каждой итерации. Приложение демонстрирует основные приёмы навигации по коду в отладчике Visual Studio.

### Код приложения

```csharp
class ArrayExample
{
    static void Main()
    {
        char[] letters = { 'f', 'r', 'e', 'd', ' ', 's', 'm', 'i', 't', 'h' };
        string name = "";
        int[] a = new int[10];
        for (int i = 0; i < letters.Length; i++)
        {
            name += letters[i];
            a[i] = i + 1;
            SendMessage(name, a[i]);
        }
        Console.ReadKey();
    }

    static void SendMessage(string name, int msg)
    {
        Console.WriteLine("Hello, " + name + "! Count to " + msg);
    }
}
```

### Использованные способы отладки в Microsoft Visual Studio

**1. Точки останова (Breakpoints, F9)**

Установлена точка останова внутри цикла `for` на строке `name += letters[i];` для приостановки выполнения и анализа состояния переменных на каждой итерации.

**2. Визуализатор данных и подсказки по данным (Data Tips)**

При наведении курсора на переменную `letters` открылся визуализатор массива, показывающий все 10 элементов с их индексами. При наведении на `name` отображалось текущее значение строки.

**3. Шаг с обходом (Step Over, F10)**

Использовался для построчного выполнения кода без входа в метод `SendMessage`, что позволило отследить изменение переменной `name` на каждой итерации цикла.

**4. Шаг с заходом (Step Into, F11)**

Применялся для входа в метод `SendMessage` и проверки передаваемых аргументов `name` и `msg` непосредственно внутри вызываемого метода.

**5. Шаг с выходом (Step Out, Shift+F11)**

Использовался для выхода из метода `SendMessage` обратно в цикл `for` метода `Main` без пошагового прохождения оставшегося кода метода.

**6. Выполнить до курсора (Run to Click / Ctrl+F10)**

Применялся для быстрого перемещения к нужной строке кода без установки дополнительных точек останова.

**7. Окно «Локальные» (Locals)**

Отображало все локальные переменные текущей области видимости (`letters`, `name`, `a`, `i`) с их текущими значениями и типами.

Переменная `name` была добавлена в окно наблюдения для отслеживания её изменений на протяжении всех итераций цикла.
