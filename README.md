# Практическая работа №7. Отладка программы — Задание 2

## Консольное приложение «Галактики» (ConsoleApp_FirstApp)

### Описание

Консольное приложение, выводящее список галактик с их названиями, расстоянием и типом. В исходном коде содержались две ошибки, из-за которых вместо типа галактики отображалось имя класса, а для одной из галактик тип не определялся вовсе.

### Обнаруженные ошибки

**Ошибка 1.** Свойство `GalaxyType` класса `Galaxy` было объявлено с типом `object` вместо `GType`, из-за чего при выводе в консоль отображалось имя класса `ConsoleApp_FirstApp.GType` вместо значения типа галактики:

```csharp
// Было (ошибка):
public object GalaxyType { get; set; }

// Стало (исправлено):
public GType GalaxyType { get; set; }
```

При попытке обращения к свойству `MyGType` через тип `object` компилятор выдал ошибку CS1061:

**Ошибка 2.** В конструкторе класса `GType` в операторе `switch` для нерегулярного типа галактики использовалась строчная буква `'l'` вместо прописной `'I'` (опечатка), из-за чего тип «Irregular» не присваивался для галактики Small Magellanic Cloud:

### Использованные способы отладки в Microsoft Visual Studio

**1. Точки останова (Breakpoints)**

Установлены в цикле `foreach` на строке `Console.WriteLine(...)` для проверки значений объекта `theGalaxy` перед выводом, а также в конструкторе `GType` для анализа логики присвоения типа галактики.

**2. Подсказки по данным (Data Tips)**

При наведении курсора на переменную `theGalaxy.GalaxyType` в режиме отладки удалось раскрыть свойство `MyGType` и убедиться, что значение корректно хранится внутри объекта, но не отображается из-за неверного типа свойства. На скриншоте видно, что переменная `type` содержит значение `73 'I'`, однако `case 'l'` не совпадает с `'I'`.

**3. Пошаговое выполнение (Step Into, F11)**

Использовалось для входа в конструктор `GType` и отслеживания прохождения через оператор `switch`, что позволило обнаружить опечатку в `case 'l'`.

**4. Продолжение выполнения (Continue, F5)**

Применялось для последовательного прохождения итераций цикла `foreach` с остановкой на точке останова, чтобы проверить значения для каждой галактики.

**5. Перезапуск отладки (Restart, Ctrl+Shift+F5)**

Использовался для повторного запуска приложения после внесения исправлений в код с сохранением установленных точек останова.

**6. Горячая перезагрузка / Изменение и продолжение (Edit and Continue)**

Попытка изменения кода во время сеанса отладки для быстрой проверки гипотезы об ошибке с типом `object`.

**7. Окно «Список ошибок» (Error List)**

Отображение ошибок компиляции при попытке обращения к свойству `MyGType` через переменную типа `object`, что подтвердило необходимость изменения типа свойства.
